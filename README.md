# Circle Clicker

[Play in your browser](https://redrookai.github.io/circle-clicker/)

Click the circle to earn points. The first generator earns 1 point per second. Each new generator makes every generator 50% stronger, giving total rates of 1, 3, 6.75 and 13.5 points per second for the first four. The shop shows the extra output from your next purchase. Buy Click Power upgrades to earn more points per click. Reloading resets progress.

Standalone HTML, CSS and JavaScript. Open `index.html` locally to play or edit it.
